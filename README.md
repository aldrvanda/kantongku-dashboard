# KantongKu - Dashboard

KantongKu is a modern financial management application designed to help users efficiently track their income, expenses, and savings. With a clean user interface built using Tailwind CSS, users can view summaries, manage transactions, and analyze their financial health seamlessly.

## Project Overview

KantongKu aims to simplify personal finance management, providing features to log income and expenses, track savings goals, and offer insights through visual data representations. By organizing financial activities in an intuitive manner, users can better understand their financial status and make informed decisions.

## Installation

To set up the project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/kantongku-dashboard.git
   ```
   
2. **Change directory**:
   ```bash
   cd kantongku-dashboard
   ```

3. **Open the project in a browser**:
   You can simply open the `index.html` file in a web browser of your choice or set up a local server if required.

## Usage

- Open `index.html` in your web browser to start using the dashboard.
- Use the navigation bar to move between the Home, Dashboard, Contact, and other pages.
- You can log in through the `login.html`, add new income and expenses through `new-income.html` and `new-expense.html`, and view savings in `savings.html`.

## Features

- **Dashboard**: Provides an overview of your financial status with visual summaries of income, expenses, and savings.
- **Income/Expense Tracking**: Easily add new income or expenses via dedicated forms.
- **Savings Goals**: Set and track savings goals to help achieve your financial objectives.
- **Visual Data Representation**: View charts and graphs that provide insights into your financial habits and growth over time.
- **Responsive Design**: Works seamlessly across various devices and screen sizes.

## Dependencies

This project relies on the following dependencies, as specified in `package.json`:
- **Tailwind CSS**: For styling the application.
- **Chart.js**: For rendering dynamic charts based on user data.
  
Note that these dependencies are loaded via CDN links directly in the HTML files.
